# Request types that declare neither [Authorize] nor [AllowAnonymous].
#
# EMPTY SINCE 10 NOVEMBER 2026, AND IT STAYS EMPTY.
#
# BSEC-003, recorded 9 November 2026 with 247 entries. AuthorizationBehavior returned next() when
# it found no [Authorize], so a request type on this list was authorised by its HTTP route, by its
# handler, or not at all -- and nothing distinguished which. The list existed so the three cases
# could be told apart one at a time, and so a NEW unannotated request type failed the build rather
# than joining them in silence.
#
# All 247 are classified. 129 took the policy their own route already named; 111 are deliberately
# public and now say why; 6 require an authenticated caller and nothing more; 1 took a policy the
# chunk parser could not attribute to it. AuthorizationBehavior now REFUSES a request carrying
# neither attribute, so the dangerous case is the one that has to be opted into.
#
# The file is kept rather than deleted, and it is kept empty. RequestAuthorizationArchitectureTests
# asserts that: a new unannotated request type cannot be waved through by adding a line here,
# because a line here now fails the build on its own. The list only ever shrank, and it has
# finished shrinking.
#
# Format (historical): <assembly>|<type name>
