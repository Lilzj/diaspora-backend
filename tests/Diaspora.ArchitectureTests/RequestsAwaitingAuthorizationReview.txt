# Request types that declare neither [Authorize] nor [AllowAnonymous].
#
# BSEC-003, recorded 9 November 2026. AuthorizationBehavior returns next() when it finds no
# [Authorize], so a request type on this list is authorised by its HTTP route, by its handler, or
# not at all -- and nothing distinguishes which. Enumerated here so the three cases can be told
# apart one at a time, and so a NEW unannotated request type fails the build instead of joining
# them in silence.
#
# RequestAuthorizationArchitectureTests holds this list at its current size or smaller, and
# requires every name on it to still be unannotated. To take a name off: add [Authorize(...)] or
# [AllowAnonymous("why")] to the type, then delete its line. The list only shrinks.
#
# AuthorizationBehavior becomes fail-closed when this file is empty. That is the rest of BSEC-003.
#
# Format: <assembly>|<type name>
